# Flap Tuning Lab｜飛翔小鳥參數實驗室

線上網站：https://shuan14408-ops.github.io/dino-tuning-lab/

調整拍翅力度、重力、速度與管道參數，親自試飛，找出最順手的遊戲手感。

## 設計理念

- **理解「參數」如何影響結果**：遊戲好不好玩，很大一部分取決於幾個數字。學生調整拍翅力度、重力、移動速度、通道高度與管道間距，馬上就能試飛，感受每個參數帶來的差異。
- **從玩家變成設計者**：學生不只是玩遊戲，而是以遊戲設計師的角度思考「什麼樣的手感最好」，練習觀察、假設、調整、驗證的流程。
- **用數據對照直覺**：畫面即時顯示分數、飛行時間，以及「飛行手感」數值（拍翅力度 ÷ 重力），讓學生把主觀感受和數字連結起來。
- **有目標的探索**：提交後系統會計算與經典參數的相似度，並解鎖經典答案。學生可以在「我的設定」和「經典參數」之間切換比較，再回頭微調。
- **可以重複嘗試**：「新題」按鈕會隨機產生一組參數，讓學生從不同的起點開始調整。

## 開發過程

1. 以大家熟悉的「拍翅小鳥」遊戲為素材，設計一個以「調整參數」為核心的學習活動。
2. 規劃要開放調整的參數、每個參數的合理範圍，以及評分方式。
3. 使用 AI 程式開發工具協助撰寫程式，再依實際試玩的結果反覆調整參數範圍、介面與評分公式。
4. 以 Next.js 開發，打包成靜態網站後部署到 GitHub Pages。
